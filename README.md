### 📌 Overview
This repository contains the source code for my personal portfolio and academic research vault. It features:
* **Academic Research & Publications:** Direct DOI links, conference details, and award highlights.
* **Featured Software & AI Projects:** Source links for time-series forecasting, distributed Java microservices, and web architectures.
